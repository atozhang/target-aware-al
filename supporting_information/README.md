# Supporting Information

This directory contains data exports and tables used in the Supporting Information (SI). The three data exports can be regenerated from the released results using the scripts listed below.

## Data exports

| File | Contents | Regeneration script |
|---|---|---|
| `data/all_benchmark_learning_curves.csv` | Mean learning curves for all tasks and methods on the 0–30% acquisition grid. Used for the SI learning curves and Fig. 4B. | `python scripts/build_si_learning_curves.py` |
| `data/experimental_efficiency.csv` | Reactions and fraction of the acquisition pool required to reach the target performance level for each task and method (first native integer-step crossing of the method-mean curve; see `results/README.md`). | `python scripts/build_si_efficiency.py` (packages `results/efficiency/efficiency_per_task.csv`, generated by `python scripts/efficiency_endpoint.py`) |
| `data/pairwise_statistical_tests.csv` | Results of all 1,180 pairwise exact Wilcoxon signed-rank tests, including Holm-adjusted p-values. | `python scripts/build_si_pairwise_tests.py` |

## Tables

### Task definitions

| File | Contents |
|---|---|
| `tables/benchmark_tasks.csv` | Definitions of all 118 prediction tasks, including dataset, data split, pool and target sizes, initial training size, model configuration, and number of repetitions. |

### Method comparisons

The six count tables summarize results across all five acquisition methods and seven evaluation windows.

| File | Contents |
|---|---|
| `tables/competitiveness/competitive_by_overall.csv` | Statistically competitive counts across all 118 tasks. |
| `tables/competitiveness/competitive_by_dataset.csv` | Statistically competitive counts by reaction dataset. |
| `tables/competitiveness/competitive_by_split_family.csv` | Statistically competitive counts by split family. |
| `tables/competitiveness/highest_mean_by_overall.csv` | Highest-mean counts across all 118 tasks. |
| `tables/competitiveness/highest_mean_by_dataset.csv` | Highest-mean counts by reaction dataset. |
| `tables/competitiveness/highest_mean_by_split_family.csv` | Highest-mean counts by split family. |
| `tables/competitiveness/task_level_classifications_a2_12.csv` | Method classifications for each task in the primary 2–12% evaluation window. |
| `tables/competitiveness/task_level_classifications_all_windows.csv` | Method classifications for each task across all seven evaluation windows. |

## Verification

The three data exports are validated by their respective generation scripts. `tests/test_window_analysis.py` checks that regenerated exports match the committed files byte for byte.

The six count tables and two task-level classification tables are recomputed and checked by:

```bash
python scripts/verify_results.py
```

Two additional summary files are kept with their corresponding results rather than in this directory:

- `results/benchmark/group_summary.csv`
- `results/efficiency/savings_intervals_100k_by_structure.csv`
