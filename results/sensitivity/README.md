# Sensitivity analyses

This directory contains analyses examining how the results depend on the acquisition window, Rh partition aggregation, and efficiency threshold.

## Files

| Path | Contents |
|---|---|
| `target_level_counts.csv` | Number of tasks reaching 70–95% of their achievable improvement within the 30% acquisition budget, for each method, using the first native integer-step crossing. Generated by `scripts/efficiency_endpoint.py`. |
| `rh_partition/` | Task classifications obtained by averaging the Rh partitions, pooling all 30 trajectories, or analyzing each partition separately. |

The full acquisition window classifications and counts are available in `../benchmark/counts_by_window.csv`. Comparisons among bootstrap resampling methods are provided in `../efficiency/savings_intervals_100k_by_structure.csv`.

## Statistical classification

For each task and acquisition window, the method with the highest mean AUC is identified. All ten pairwise comparisons are evaluated using exact, two-sided paired Wilcoxon signed-rank tests, with Holm correction across the ten comparisons at α = 0.05.

A method is classified as **detected worse** if its mean AUC is lower than the highest mean and the adjusted p-value is below 0.05. Otherwise, it is classified as **statistically competitive**. This classification does not establish equivalent performance.

Paired differences are rounded to 12 decimal places before handling zeros and ties.

Friedman statistics are reported alongside the classifications in `../benchmark/per_task_classification.csv` as a diagnostic. They do not affect the classification.

## Acquisition window sensitivity

The evaluation uses seven acquisition windows, with 2–12% of the acquisition pool as the primary window.

EPIG is statistically competitive on 102–107 of the 118 tasks across these windows. The corresponding counts for the other methods generally decrease for later windows.

The declining competitiveness counts for the other methods may reflect increasing performance differences, greater ability to detect those differences in later windows, or both. These effects are not distinguished by the analysis.

Full results, including highest-mean counts, are provided in `../benchmark/counts_by_window.csv`.

## Rh partition aggregation

The primary analysis averages the three Rh partition values within each repetition seed before statistical testing. Sensitivity analyses instead pool all 30 trajectories or analyze each partition separately.

For the primary acquisition window, EPIG is statistically competitive on 105 tasks under both the primary and pooled analyses. The counts for the three individual partitions are 107, 105, and 105.

The full results are provided in `rh_partition/counts.csv` and `rh_partition/summary.json`.
